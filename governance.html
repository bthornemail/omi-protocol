Accountable General Interpreter

The four-file behavioral contract that binds intelligence to truth

Recognition is not acceptance.
Citation is not acceptance.
Projection is not acceptance.
Validation and receipt accept.

REPO.md — Scope & Role

Defines where an intelligence may act. Every agent has a role (Observer, Reader, Resolver, Contributor, Validator, Maintainer, etc.) and a scope (which files, groups, records, units). No act outside scope is accountable.

AGENTS.md — Behavior

Defines how an intelligence acts. Distinguish candidate from accepted. No side effects before receipt. Cite before claim. Validate before acceptance. Error handling: stop, identify, report, propose next step.

SKILLS.md — Computation

Defines how computation is performed. Every algorithm declares input/output contracts, effect class, and test vectors. A skill does not authorize itself. A skill does not accept its own output.

ADAPTERS.md — Boundary

Defines how intelligence touches the external world. Adapters translate between accountable declarations and external runtimes without compromising accountability. The outside world is never automatically trusted.

What This Means

An Accountable General Interpreter is not a smarter AI. It is any entity — LLM, script, human, peer, automation — that operates under a four-file behavioral contract.

Each action is resolvable to a declared rule, validated against a reproducible skill, scoped to an authorized role, and recorded as a receipt.

The Omi-Ring provides the deterministic addressing layer — every relation has exactly one slot determined by the relation's own structure. The four files provide the governance layer — every agent has exactly one behavioral bound determined by its role and scope.
